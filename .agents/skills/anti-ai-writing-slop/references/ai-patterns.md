# AI patterns to catch

## Support-bot opening

Weak:

```text
Thank you for sharing the additional context. I understand your concern and will review this carefully.
```

Better direction:

```text
I see the conflict. The deadline and the review step can't both fit as written.
```

## Abstract verb soup

Weak:

```text
We should optimize the experience to improve alignment, clarity, and engagement.
```

Better direction:

```text
Cut the second form step, rename the button, and show the delivery date before checkout.
```

## Hollow certainty

Weak:

```text
This will definitely solve the issue and create a much stronger experience.
```

Better direction:

```text
This should remove the main point of confusion. We'd still need to test whether people notice the date.
```

## Consultant polish

Weak:

```text
The proposed direction is viable, provided we maintain scope discipline and prioritize the highest-impact components.
```

Better direction:

```text
This can work if we keep it small. I'd fix the 2 screens people see first and leave the settings page alone.
```

## Fake punchiness

Weak:

```text
Less friction. More growth.
```

Better direction:

```text
Removing the extra step should get more people to the payment screen.
```
