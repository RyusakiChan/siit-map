# Starter voice profile

Use this profile only when the user, brand, or project does not provide a stronger one.

## Default rules

- Start close to the point.
- Prefer short paragraphs, usually 1 to 3 sentences.
- Use specific nouns, numbers, and actions when the evidence supports them.
- Mix short and longer sentences instead of repeating one rhythm.
- Prefer verbs that show what changes.
- Preserve honest uncertainty.
- Keep distinctive wording when it is clear.
- Use contractions in informal English.
- Remove transcript noise, false starts, and accidental repetition.
- End with a concrete action, implication, estimate, or boundary when appropriate.

## Evidence rules

- Prefer 3 or more representative samples from the same channel.
- Separate stable voice traits from one-off topic language.
- Do not infer biography, identity, or client relationships from a writing sample.
- Do not publish or quote private samples unless the user explicitly asks.
- When evidence is thin, make fewer changes and label the uncertainty.
